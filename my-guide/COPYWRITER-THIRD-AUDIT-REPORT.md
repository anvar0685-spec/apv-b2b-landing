## III.4 Конфликты с ролью 04 (SEO) — зафиксировать решение до правок

1. **Слово `compliance` в description/title/manifest** может быть **намеренным** для выдачи и закупочного языка. Роль 05 предлагает русские синонимы; роль 04 оценивает потерю/выигрыш по запросам и CTR сниппета.
2. **`TCO` в категории блога** — то же самое: ключ vs чистота русского.
3. **Programmatic longread** — менять «поставка» может слегка сместить «юридическую» коннотацию; если юрист настаивает на формулировке из договора, можно **один раз** дать оговорку «в договоре может использоваться термин…», но не размножать на всех URL.

## III.5 Что сознательно не входило в этот третий аудит (границы объёма)

- **Построчный разбор всех 40 статей блога** — только grep + выборочная логика корпуса; для глубокого построчного прохода нужен отдельный чеклист или часовой бюджет.
- **Alt-тексты изображений, aria-only строки** — по запросу.
- **Юридическая валидация** формулировок гарантий/оферты — не зона 05.
- **Полный проход всех programmatic пар** на уникальность «между соседними городами» — оценочно в §III.1; детальный анти-спам для 04.
