# Отчёт по дизайну и редакции без фотографий (2026-10-10)

## Визуальная система

- Акцент CTA в светлой теме: `#0F766E` (`--accent`, `--cta` в `globals.css`).
- Переиспользуемые SVG: `src/components/graphics/warehouse-schematic.tsx` (hero, процесс, полосы услуг/отраслей, кейсы).
- Фотографии убраны из hero, виджета менеджера, `production-visual-strip`; декоративные sparkline на главной и в кейсах сняты.

## Главная и навигация

- Hero: схема склада вместо `hero-sklad.jpg`; ставки без псевдографика.
- `#process`: компактная сетка 4 этапа (`process-sticky-split.tsx`).
- `#why-us`: список с пиктограммами вместо сетки карточек.
- Шапка: CTA «Обсудить задачу», ссылка «Калькулятор»; «Команда»/«Пресса» убраны из sitemap.
- Менеджер: свёрнут по умолчанию, монограмма «А», без статуса «онлайн».

## Калькулятор и заявка

- Калькулятор: 4 шага (команда → график → срок/опции → результат), боковое резюме, таблица и примеры в `<details>`.
- Формула и `staffing-url-params` без изменений логики.
- Заявка: шаг 1 — задача, шаг 2 — контакты, шаг 3 — проверка и согласия.

## О компании

- `/o-kompanii`: вводная и три блока + менеджер; редиректы `/komanda`, `/pressa` → `/o-kompanii` (308 в `next.config.mjs` + `permanentRedirect` в page).
- Документы: вводная для ИП без обещания устава в meta/hero.
